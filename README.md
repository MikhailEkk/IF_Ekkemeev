## Технологии
- **Язык**: Java 17
- **Тестирование**: JUnit 5
- **UI Automation**: Selenide, Cucumber
- **Конфигурация**: Owner
- **Отчетность**: Allure Report
- **Сборка**: Maven

## Использование
Клонируйте репозиторий
```bash
git clone https://github.com/MikhailEkk/IF_Ekkemeev.git
```

## Тестирование
Для запуска тестов выполните команду:
```bash
mvn test
```
