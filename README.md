## Технологии
- **Язык**: Java 17
- **Тестирование**: JUnit 5
- **BDD Test**: Cucumber
- **Отчетность**: Allure Report
- **Сборка**: Maven

## Использование
1. Клонируйте репозиторий
```bash
git clone https://github.com/MikhailEkk/IF_Ekkemeev.git
```
2. Установите зависимости
```bash
mvn clean install
```

## Тестирование
Для запуска тестов выполните команду:
```bash
mvn clean test
```
